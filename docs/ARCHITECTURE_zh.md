# 知纹架构全景 v3.2

## DNA 生命系统同构

知纹的架构不是比喻——是一对一的生命系统同构。每个生物学概念在代码中都有精确对应的模块：

| 生物学概念 | 对应模块 | 功能同构 |
|---|---|---|
| **DNA（基因组档案）** | `genome_core.py` — 523行 | AGCT 碱基对 · 双链互补 · 半保守复制 · 翻译 |
| **mRNA（临时指令）** | `genome_pipeline.py` — 519行 | 转录 → 密码子 → 蛋白质表达 |
| **tRNA（搬运翻译）** | `dna_executor.py` — 519行 | 24 动作处理器：搜索/模拟/验证/对比 |
| **操纵子（聚合单元）** | `operon.py` — 376行 | 同族基因并发 · 阻遏物调控 |
| **rRNA（蛋白工厂）** | `pipeline.py` — 345行 | 20+ 层管线编排 |
| **miRNA（刹车调控）** | `cross_session.py` — 267行 | 反同质化六防线 |
| **snRNA（编辑器）** | `genome_guardian.py` — 456行 | 六层基因组保护 |
| **甲基化（表观调控）** | `epigenetics.py` — 405行 | 同基因·不同表达 |
| **剪接体（路由）** | `route_fast.py` — 67行 | 三级路由决策 |

## 性能基线

### 纯计算延迟（无 LLM，全 Python）

| 操作 | 耗时 | 说明 |
|---|---|---|
| 路由决策 | <1ms | `route_fast.py` 关键词匹配 |
| 知识图谱检索 | <5ms | 向量检索 top-5 |
| 数据质量闸 | <5ms | 四道闸门全过 |
| 管线编排 | <10ms | 20+ 层串联（无 LLM） |
| 缓存命中 | 0ms | 搜索/路由/φ/计算 均有 TTL |

### 管线开销（不含 LLM）

| 路由级别 | 开销 | 组成 |
|---|---|---|
| 🟢 fast | 0ms | 三级路由 + 直接 LLM |
| 🟡 standard | <10ms | 路由 + KG 检索 + 闸门（简化） |
| 🔴 deep | ~2s | 路由 + 规划 + DAG + 闸门 + 推理 |

### LLM 延迟（网络依赖）

| 操作 | 典型延迟 | 说明 |
|---|---|---|
| 网络搜索 | 7.5s | 取决于搜索引擎 API |
| LLM 生成 | 3-8s | 取决于模型和 token 数 |
| 流式首 token | 0.5s | 逐 token 返回 |
| 重复查询（缓存） | 0ms | 路由缓存 60s |

### 缓存策略

| 缓存类型 | TTL | 命中效果 |
|---|---|---|
| 搜索缓存 | 60s | 同一查询免搜索 |
| 路由缓存 | 60s | 同问题复用路由决策 |
| φ 缓存 | 30s | 织星 φ 值本地缓存 |
| 计算缓存 | 60-300s | Benford/模拟结果复用 |

### 整体优化

| 指标 | 优化前 | 优化后 | 提升 |
|---|---|---|---|
| 管线总开销 | 7,401ms | 2,127ms | ↓71% |
| 感知延迟 | 8s 空白 | 0.5s 首 token | ↓94% |
| 重复查询 | 8s | 0ms | 即时 |
