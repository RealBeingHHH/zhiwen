你跟 AI 说话的时候，有没有这种感受——

> 「帮我分析一下日本通缩成因和 MMT 政策效果。」

它回了一千字。看起来很有道理。但你仔细看——那些数字是它编的。那些因果是它猜的。那个「综上所述」前面少了一个关键的中间步骤，它跳过去了——因为它根本不知道自己在说什么。

它只是把训练数据里最像答案的那段文字吐给了你。它没有**想**过。

## 五个痛点，一次解决

### 痛点 ①：LLM 会编数字

每个 ChatGPT 用户都有这个经历——数字看起来真，一个都不对。

**怎么办？** 每条数据过四道闸门。Benford 定律检测人造数字。熵场检测数据是不是被人「均匀化」过。τ 锚定检查每个数字有没有来源。φ 漂移监控 LLM 有没有偷偷塞新数字。

> 你看到的每个数字，后面都有锚。没锚的，标红。

---

### 痛点 ②：「深度研究」只是多搜了几个词

市面上的「Deep Research」在做什么？把你的问题拆成关键词 → 搜 → 塞进长 prompt → LLM 吐。

这不是研究。这是**更长的瞎猜**。

**知纹做什么？** 把你的问题劈成一个个**可独立验证的原子问题**——它们之间还有 DAG 依赖关系。子问题 3 依赖子问题 1 的结果。子问题 4 依赖 1、2、3。拓扑排序。无依赖的先跑，三路并发。每个子问题独立搜索、独立验证、独立过闸。

```
"分析日本通缩成因与MMT政策效果"
  
  不是: 搜"日本通缩 MMT 政策 效果" → 塞进 prompt → 吐答案

  而是: 劈成——
    子1: 日本通缩的主要成因是什么？       (叶节点, 独立)
    子2: MMT的核心主张是什么？            (叶节点, 独立)
    子3: 日本政策后数据怎么变化？          (叶节点, 独立)
    子4: 通缩成因与MMT有因果关系吗？       (依赖1,2,3)
    子5: 外部因素如何干扰？                (半依赖)
    ROOT: 综合                              (依赖全部)
  
  然后: 3个叶节点并发执行 → 4就绪 → ROOT聚合
```

---

### 痛点 ③：慢。你好不容易鼓起勇气问了一个复杂问题，然后看了 8 秒空白

8 秒。你可以刷三条短视频。可以喝完半杯咖啡。可以决定「算了不问了」。

**我们做了三件事：**

1. **流式输出** — 首字 0.5 秒到达。不用等整个回复生成完。
2. **三级路由** — "你好"直接走 LLM（0ms 管线开销）。"分析..."才启动深度管线。
3. **60 秒缓存** — 同一个问题别再搜一遍。路由缓存、搜索缓存、φ 缓存、计算缓存——重复查询 0ms。

```
优化前: 提问 → 8秒空白 → 全部出现
优化后: 提问 → 0.5秒看到"...日本...通缩..." → 逐字流出
```

---

### 痛点 ④：每次都是陌生人

你花了 15 分钟问完了一个复杂的日本经济分析。然后你说「那通胀率呢？」

它从零开始。

**知纹会记住**——不是存聊天记录。是存**纹路**：上次你问日本经济时，劈成了哪几个子问题，推理链长什么样。下次你追问，它认出来了——「这是上一轮的延续，复用 DAG 结构」。

---

### 痛点 ⑤：你不知道该信什么

LLM 说「MMT 在日本效果显著」。你怎么知道不是胡说的？

**知纹每条结论都有追溯链：**

```
[追溯: 公理A1(MMT主权货币不受税收约束)→实证研究→闸过] 
日本央行大规模购债后基础货币增长300%, 但通胀率仍低于1%
[链:强]

[对抗自检: 攻击→"基础货币增长是否因其他因素?"→存活]
```

每条结论——从哪个公理出发、用什么方法、过了哪道闸门、链强度多少——全部可追溯。不确定的数据标注「待验证」。数据不足会说「我试了，信息不全」。

---

## 知纹不是 Agent

Agent 是「我有一个工具列表，LLM 决定调用哪个」。知纹是「问题内部有天然的纹路，我看见了，我沿着纹路把它劈开了」。

> 一个是被动地拼装答案。
> 一个是主动地发现结构。

## 66 个模块。23,000 行。一套逻辑。

没有 LangChain。没有 AutoGPT 的 100 个依赖。纯 Python。FastAPI。

```
python3 server.py --port 9200
```

一条命令。然后在另一个终端：

```bash
curl -X POST http://localhost:9200/api/chat/stream \
  -H "Content-Type: application/json" \
  -d '{"message":"分析日本通缩成因与MMT政策效果"}'
```
